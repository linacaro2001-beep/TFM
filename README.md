# TFM - Predicción de Vulnerabilidad Socioeconómica y Exclusión Financiera en Hogares Españoles
Trabajo Fin de Máster desarrollado en el Máster de Data Science, Big Data & Business Analytics de la Universidad Complutense de Madrid.

El objetivo del proyecto es identificar hogares españoles en situación de vulnerabilidad socioeconómica mediante técnicas de Machine Learning utilizando datos de la Encuesta de Condiciones de Vida (INE). 

## Tecnologías utilizadas
Python
Pandas
NumPy
Scikit-Learn
SHAP
Gradio
Matplotlib
Seaborn

## Metodología
Limpieza y transformación de datos.
Ingeniería de variables.
Modelización predictiva.
Comparación de algoritmos:
Regresión Logística
Random Forest
SVM
Interpretabilidad mediante SHAP.
Desarrollo de aplicación interactiva en Gradio.

## Resultados
Random Forest fue seleccionado como modelo final por ofrecer el mejor equilibrio entre precisión y capacidad predictiva.
